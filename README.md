# WebSocket GameHub

A full Gamehub driven by a socket manager to allow the use of phones as controllers on a TV screen.

## Description

The project is to build a GameHub responding to a specific problem that we might all had.

*When you go to your friend's house, you might want ot play videogames with him. 
But sometimes, a big problem prevent you from playing. You are missing a controller. 
What if you could play without having a controller ?*

This project brings a solution to this situation by using a websocket system to allow your phone to be used as a controller.
